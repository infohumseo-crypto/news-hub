# The Daily Draft

A fast, responsive, dark-mode-ready blog built with plain HTML, CSS and JavaScript. No build step needed.

## Publish on GitHub Pages (free)

1. Create a **public** repository on GitHub (name it `YOUR-USERNAME.github.io` for the shortest address).
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After 1 to 2 minutes your site is live at:
   - `https://YOUR-USERNAME.github.io/` (if the repo is named `YOUR-USERNAME.github.io`)
   - `https://YOUR-USERNAME.github.io/REPO-NAME/` (any other repo name)

## Add a new post

1. Copy `posts/seo-basics.html`, rename it, and edit the content.
2. Add an entry to the `POSTS` list at the top of `script.js`.

## Customize

- Blog name: search for "The Daily Draft" and replace it.
- Colors: edit the variables at the top of `style.css`.
- Newsletter form: connect it to a service such as Buttondown or Formspree (currently a demo).
