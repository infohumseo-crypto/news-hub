Build and Host a Free Website on GitHub Pages

Oct 8, 2026 · 4 min read

GitHub Pages serves static websites straight from a repository, for free, over HTTPS. It is a great home for a blog, portfolio or documentation site.

Steps

  1. Create a new public repository on GitHub.
  2. Upload your index.html, CSS and other files.
  3. Open Settings → Pages.
  4. Under Source, choose Deploy from a branch, select main and / (root), then save.
  5. Wait a minute or two and open your live link.

Your web address

If the repository is named username.github.io, the site lives at the root of that address. Any other repository name is served at a sub-path, for example:

https://username.github.io/my-blog/

Use your own domain later

You can connect a custom domain in the same Pages settings once you are ready. Until then, the free github.io address works well.
