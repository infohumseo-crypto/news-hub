On-Page SEO Checklist: 15 Things to Check Before You Publish

On-page SEO means the things you control on the page itself: your words, headings, links, images and code. Run through this checklist before you publish each article. It takes about ten minutes and prevents the most common mistakes.

Content and intent

  1. Match search intent. Make sure the format of your page fits what searchers expect. Our keyword research guide explains how to check this.
  2. Answer the question early. Put the key answer near the top, then explain.
  3. Be original and useful. Add examples, your own experience or data that other pages lack.
  4. Check facts and update dates. Outdated advice loses reader trust.

Title, description and URL

  1. Write a clear title tag. Include the main keyword near the start and keep it concise so it is not cut off in results.
  2. Write a helpful meta description. It does not directly boost rankings, but a clear summary can earn more clicks. Search engines may rewrite it, so make sure the page itself is relevant.
  3. Use a short, readable URL. For example /on-page-seo-checklist is better than a long string of numbers.

Headings and structure

  1. Use one H1. It should match the page topic.
  2. Organize with H2 and H3 subheadings. This helps both readers and search engines scan the page.
  3. Keep paragraphs short. Two to four sentences read well on phones.

Images and media

  1. Add descriptive alt text. Describe what the image shows. It helps accessibility and image search.
  2. Compress images. Large files slow down your page. Use modern formats where possible and set width and height to avoid layout jumps.

Links and technical basics

  1. Add internal links. Link to related articles using descriptive anchor text instead of "click here". See also our guide to SEO basics.
  2. Link to trustworthy sources when you reference facts, and make sure every link works.
  3. Check mobile view and speed. Open the page on a phone, and make sure it has a viewport tag, readable text and no heavy scripts.

Bonus: submit your sitemap

A sitemap lists the pages you want search engines to find. Add yours in Google Search Console after you publish, and use the URL inspection tool to request indexing for new posts. Indexing is never guaranteed, but this helps new pages get discovered.

Quick copy-and-paste checklist

  • Intent matched and answer up top
  • Title, description and URL written
  • One H1, clear H2 and H3 headings
  • Images compressed with alt text
  • Internal and external links checked
  • Mobile view and speed tested

Conclusion

None of these steps is difficult, but doing them every time sets your posts apart. Pair this checklist with strong headlines by reading how to write SEO-friendly titles and meta descriptions.
